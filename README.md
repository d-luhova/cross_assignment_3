Фінальний проєкт

Було додано новий екран Profile, де користувач може зберігати своє ім’я та номер телефону. Для переходу на цей екран на головній сторінці реалізовано іконку користувача в блоці HomeHero. Дані профілю зберігаються локально та автоматично підставляються у форму бронювання. Для керування глобальним станом профілю використано Context API, а для покращення модульності створено окремий компонент ProfileForm. Також у формах реалізовано валідацію даних і Toast-повідомлення після успішного збереження профілю.

Щодо покращення візуалу, то було інтегровано тіні до карток ресторанів, бронювань, основних кнопок, нижньої навігації, Toast-повідомлень, календаря, вибору часу та полів вводу. Також з'явився візуальний feedback при натисканні на картки, кнопки та елементи нижньої навігації. Переходи між екранами зроблено плавнішими завдяки налаштуванню однакової анімації в stack navigation. Для покращення UX у формах додано активний стан полів вводу - border змінює колір, зокрема в залежності від успіху валідації.
